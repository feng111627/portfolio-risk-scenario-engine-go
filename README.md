# portfolio-risk-scenario-engine-go

本地投资组合记账与风险情景评估引擎。用本地行情快照模拟市场数据，
保证记账、估值、情景评估各入口下的头寸、估值与风险结论一致且可解释。

## 模块结构

| 包 | 职责 |
|---|---|
| `ledger` | 订单、成交、头寸与已实现/未实现盈亏的记账 |
| `market` | 本地行情快照与行情有效性判定 |
| `risk` | 基于行情快照的估值与敞口/风险度量 |
| `scenario` | 情景/压力场景的串行与并发评估 |
| `integration` | 端到端一致性验证（测试包） |

## 记账规则（ledger）

- **订单生命周期**：`Open -> PartiallyFilled -> Filled`，未完成的订单可撤销为
  `Cancelled`。已关闭（Filled/Cancelled）的订单拒绝任何后续操作。
- **成交入账**：成交按 `Fill.ID` 幂等去重——**重复到达的成交只计价一次**，
  第二次起返回 `Duplicate=true` 且不改任何状态。
- **迟到成交**：订单已撤销后到达的成交以 `LATE_FILL` 拒绝，不污染已有头寸。
- **冲突校验**：超量成交（`OVER_FILL`）、标的/方向不符（`SYMBOL_MISMATCH`）、
  未知订单（`UNKNOWN_ORDER`）、非法数量/价格（`INVALID_QUANTITY`/`INVALID_PRICE`）、
  禁止卖空时的超仓卖出（`INSUFFICIENT_POSITION`）均以**可区分的原因**拒绝。
- **盈亏口径（平均成本法）**：
  - 同向加仓：加权平均成本，无已实现盈亏；
  - 反向减仓/平仓：按平均成本结转已实现盈亏 `closing * (price - avgCost)`（空头取反）；
  - 翻仓：先结清旧方向全部盈亏，剩余数量以成交价作为新方向成本。
- 未实现盈亏不在账本中固化，由估值侧按 `Qty * (最新价 - 平均成本)` 现算，
  保证各入口口径一致。

## 行情有效性口径（market）

- 每个标的只保留**最新有效**行情；`Apply` 只接受 `Seq` 严格递增的行情，
  乱序或重复到达以 `OUT_OF_ORDER` 拒绝，绝不回滚到旧价。
- 价格必须为正，否则 `INVALID_PRICE`。
- 估值时按 `asOf` 检查行情年龄：超过快照配置的 `maxAge` 视为过期，
  返回 `STALE_QUOTE`；标的无行情返回 `NO_QUOTE`。
- **任何缺失或过期行情都不会被静默使用**：估值直接失败并给出可区分原因。
- `Clone` 提供深拷贝，是并发情景评估的隔离基础。

## 风险度量（risk）

- 估值输入为头寸列表 + 行情快照 + 估值时刻，输出 `Report`：
  逐头寸的市值/未实现盈亏，组合层面的 `TotalValue`（净市值）、
  `GrossExposure`（Σ|市值|）、`NetExposure`（Σ市值）、已实现/未实现盈亏合计。
- 输出是输入的纯函数，头寸按标的排序，结果**可复现**；
  多头市值与未实现盈亏随行情价格**单调**（有测试保证）。
- 任何头寸拿不到有效行情，整个估值失败，不产出部分结果。

## 情景评估（scenario）

- 情景 = 一组命名价格冲击 `{Symbol, Pct}`，冲击价 = 基准有效价 × (1+Pct)，
  施加在快照副本上（保持原时间戳与有效性口径），再调用 `risk.Value` 重估。
- `PnLImpact = 情景总市值 - 基准总市值`，可手工核算解释。
- `EvaluateAll`（串行）与 `EvaluateParallel`（并发）**结果完全一致**：
  同顺序、同数值。并发实现中每个情景在独立快照副本上评估，输入只读，
  无共享可变状态（`-race` 下验证）。
- 单个情景失败（如冲击了无行情标的）只记录在该结果的 `Err` 中，
  **不污染其他情景**；`ctx` 取消时整体返回错误且**不产出任何结果**。

## 验证方式

```bash
go build ./...          # 编译
go test ./... -v        # 单元测试，日志标注每个用例覆盖的业务与结果
go test ./... -race     # 竞态检测（含并发情景评估）
```

测试覆盖的关键边界：

- **ledger**：部分成交累积、平均成本法已实现盈亏、重复成交幂等、
  迟到成交拒绝、七类非法/冲突操作的可区分原因、禁止卖空、翻仓；
- **market**：乱序/重复行情拒绝、过期行情拒绝、缺失行情、非法价格、
  Clone 隔离；
- **risk**：估值可复现、缺失/过期行情导致估值失败、风险指标随价格单调；
- **scenario**：并发与串行结果一致（workers=1/2/8）、PnLImpact 可解释、
  单情景失败隔离、取消不产出结果、输入不被修改；
- **integration**：含重复/迟到成交的事件流经账本、估值、情景三个入口
  结论一致；过期行情在所有估值入口被一致拒绝。
